# Aposento Alto

**Portal de Oração e Espiritualidade Cristã**

Um lugar de encontro com Deus — gratuito, amoroso e feito com fé.

## Funcionalidades

- 📖 **Versículo do Dia** — palavra diária com 25+ versículos
- 🕯️ **Timer de Oração** — temporizador com som e presets de 5 a 60 min
- 📝 **Diário Espiritual** — registro local de reflexões e testemunhos
- 🙏 **Mural de Intercessão** — pedidos de oração da comunidade
- ✨ **Loja Cristã** — produtos digitais e físicos (em breve)

## Tecnologia

HTML5 + CSS3 + JavaScript puro. Sem dependências. Sem frameworks.

> como de um vento veemente e impetuoso." — Atos 2:1-2
